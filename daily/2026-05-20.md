## 今日笔记
今天我继续系统学习了 AI 相关内容，并开始把几个核心概念串起来理解，而不再把它们看成孤立术语。

### 我目前对 AI 的理解
1. **LLM**  
   LLM 本质上是一个基于上下文预测下一个 token 的概率生成模型，不是数据库，所以会出现幻觉和知识过时。

2. **Prompt**  
   Prompt 是给模型的任务说明和约束，可以控制模型的角色、输出格式和任务目标，但它本质上仍然是软约束。

3. **Context Window**  
   Context 是模型当前能看到的信息范围，包括历史对话、系统指令、工具结果和检索内容；超出 context 的内容模型就“看不到”。

4. **RAG**  
   RAG 的核心是“先检索资料，再生成回答”。它通过把外部知识放进 context，让模型能够回答最新或私有数据相关的问题。

5. **Workflow**  
   Workflow 是把复杂任务拆成多个步骤并按流程执行，提高 AI 输出的稳定性和可控性，本质上是一种工程化约束。

6. **Agent**  
   Agent 是能够围绕目标进行多步行动的 AI 系统，它会根据当前状态决定下一步做什么。

7. **Tool Use**  
   Tool use 是让模型调用外部工具，例如搜索、运行代码、查数据库等，让 LLM 从“能聊天”变成“能做事”。

8. **Framework**  
   Framework 的作用是组织 model、tools、workflow、memory、RAG 等模块，让 AI 产品更可控、可维护和可扩展。

### 今天最重要的理解
如果把这些概念串起来看，可以这样理解：

- **LLM** 是核心生成能力
- **Prompt** 决定任务表达方式
- **Context** 决定模型当前能看到什么
- **RAG** 负责把外部知识送进 context
- **Tool Use** 让模型能调用外部能力
- **Workflow** 让复杂任务按步骤稳定执行
- **Agent** 是围绕目标做多步决策和行动的系统
- **Framework** 则把这些模块组织成一个更完整、可维护的产品或工程体系

这让我开始把 AI 从“单次问答工具”理解成“可设计的系统”。
