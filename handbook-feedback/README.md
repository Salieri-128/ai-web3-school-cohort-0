# Handbook Feedback 流程

这个目录用来沉淀学习过程中对 Handbook 的问题与建议。

## 何时记录 feedback
当你遇到以下情况时，都值得记录：
- 某个概念看完还是不清楚
- 术语边界不明确
- 页面有错别字或表达不顺
- 示例太少，无法帮助你落地
- 链接 / 资料已过期
- 结构组织可以更清楚

## 推荐工作流
1. 学习时先把卡点记在 `daily/YYYY-MM-DD.md`
2. 当天或隔天把值得沉淀的问题整理成独立 feedback 文件
3. 每条 feedback 尽量包含：
   - 页面链接
   - 问题描述
   - 建议改法
   - 来源 / 为什么会卡住
4. 如果后续问题解决了，也可以在原 feedback 里补充“后续理解”

## 命名建议
文件名建议：
- `2026-05-18-context-page-wording.md`
- `2026-05-19-wallet-section-example-gap.md`

## 目标
让这个仓库里的 feedback：
- 可公开访问
- 可索引
- 可被后续分析和改进流程使用
